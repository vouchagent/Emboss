# API Reference

Everything below imports from `emboss` unless a submodule is shown.

## Document

```python
Document(
    title="",              # PDF metadata and title block
    author="",
    subject="",
    keywords="",           # comma-separated
    language="en-US",      # BCP 47
    style="corporate",     # preset name or StyleSheet
    brand=None,            # BrandKit, layered on top of `style`
    page=PageSpec(),       # geometry in points
    page_styles={},        # name -> PageSpec, switched via PageBreak.page_style
    content=[],            # block elements
    header=None,           # HeaderFooter
    footer=None,           # HeaderFooter
    header_text=None,      # simple running header
    footer_text=None,
    page_numbers=True,
    page_number_format="arabic",  # "arabic", "roman", or "ROMAN"
    front_matter_pages=0,  # front pages numbered i, ii, ...; body restarts at 1
    tagged=True,           # PDF/UA structure tree
    legal=None,            # LegalFeatures
    pdfa=False,            # PDF/A-2b (or -3b, see below) conformance
    toc=False,             # auto table of contents
    color_mode="rgb",      # "rgb" or "cmyk"
    redactions=None,
    signatures=None,
)
```

```python
doc.chart(chart_type, labels, values, ...)

```

## Block elements

`Heading`, `Paragraph`, `TextRun`, `BulletList`, `NumberedList`, `Table`, `TableCell`, `Image`, `Chart`, `Series`, `CodeBlock`, `MathBlock`, `Callout`, `Footnote`, `BibliographyBlock`, `Citation`, `SvgBlock`, `HorizontalRule`, `PageBreak`. Front matter and long-form apparatus: `CoverPage`, `Abstract`, `Author`, `Authors`, `PullQuote`, `Stat`, `StatTiles`, `TableOfContents` (and the `ListOfFigures`/`ListOfTables` convenience constructors), `Appendix`, `Index`, `GlossaryEntry`, `Glossary`. Also available (JSON tag `blockquote`): `BlockQuote`. Supporting types: `PageSpec` (with `PageSpec.letter()`, `.a4()`, `.a5()`, `.legal()`, `.compact()` constructors), `HeaderFooter`, `LegalFeatures`, `BrandKit`. See the [EmbossSpec Format](/spec-format) for fields.

## Styles

```python
from emboss import Style, StyleSheet, PRESETS, resolve_preset
```

`PRESETS` maps the seven preset names to `StyleSheet` instances; `resolve_preset(name)` fetches one; `Style`/`StyleSheet` build custom themes.

## BrandKit

```python
from emboss import BrandKit, apply_brand
```

`BrandKit(name, version="1.0", primary=, accent=, ink=, muted=, palette=(), heading_font=None, body_font=None, mono_font=None, footer_text="", logo=None)` -- an immutable, versioned brand; pass it as `Document(brand=...)`. `apply_brand(stylesheet, brand)` is what `Document.stylesheet` calls internally to layer it onto a preset. `brand.series_palette(n)` / `brand.derived_palette(n)` build a deterministic chart palette from `primary`/`accent`; `brand.to_dict()`/`BrandKit.from_dict()` round-trip through JSON. See [Color and Print](/color) for the contrast-safe color derivation.

## Typography

```python
from emboss import FontRegistry, FontMetrics, Hyphenator, LineBreaker
from emboss.bundled_fonts import register_bundled_fonts, bundled_font_path
```

`FontRegistry.register(name, path, bold=, italic=)` embeds a TTF/OTF. `Hyphenator.from_pattern_file(path)` loads TeX pattern files for other languages. `LineBreaker` exposes the Knuth-Plass parameters (`tolerance`, `hyphen_penalty`, `ladder_limit`, `protrusion`, `avoid_rivers`).

## Self-describing PDFs and diff

```python
from emboss import assign_node_ids, derive_node_id, layout_map_json
from emboss import (
    document_to_spec_dict, document_from_spec_dict,
    recover_from_attachment, recover_from_structure_tree, strip_pdf,
)
from emboss import DiffResult, diff_documents, render_redline, word_diff
from emboss import MANIFEST_FILENAME, ReproductionReport, build_manifest, reproduce
```

`Document.render(embed_spec=True, manifest=True)`, `Document.from_pdf(...)`, `doc.layout_map()`, `doc.patch(node_id, **changes)`, and `strip_pdf` are the usual entry points; the functions above are their building blocks (canonical spec serialization, node id assignment, structure-tree recovery, manifest construction). `diff_documents`/`render_redline` diff two documents by node id and render a redlined PDF; `reproduce()` (also `emboss reproduce report.pdf`) recovers, re-renders, and structurally compares a PDF against itself. See [Self-Describing PDFs](/provenance).

## Redaction and encrypted attachments

```python
from emboss import RedactionRule, redact_document, RedactionMark, apply_redactions
from emboss import encrypt_attachment, decrypt_attachment
```

`Document.redact(rules)` (construction-time, the honest kind) matches whole blocks by node id, regex/predicate, or element type and removes or replaces them before rendering. `RedactionMark`/`Document.redactions` is the older post-render masking mechanism, kept for callers without a `Document`. `Document.attach_encrypted(name, data, password)` queues an AES-256-GCM-encrypted `/AF` attachment; `decrypt_attachment` reverses it.

## Signing

```python
from emboss import (
    SignatureField, build_signature_appearance, build_sig_field_dict,
    build_acroform, can_sign, sign_pdf,
    build_docmdp_reference, build_certifying_signature, build_perms_dict,
)
```

`Document(signatures=[SignatureField(...)])` renders the visual field and AcroForm entry at render time; `sign_pdf(pdf_bytes, private_key_path, cert_path, certify=False, docmdp_permission=2)` injects the PKCS#7 signature afterward, requires `pip install emboss-pdf[signing]`, and with `certify=True` produces a DocMDP certification signature (ISO 32000-1 12.8.2.3).
